# homebrew-tap

Homebrew tap so libraries/tools created can be installed through homebrew too.

## randwallpaper

```bash
curl -sL https://github.com/MichaelWiciak/randwallpaper/archive/refs/tags/vx.x.x.tar.gz | shasum -a 256
```

Copy the SHA into the `randwallpaper.rb` script.
If the command gives you `d5558cd419c8d46bdc958064cb97f963d1ea793866414c025906ec15033512ed` you have inputted a non-existent version tag.
